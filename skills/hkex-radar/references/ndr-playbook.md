# 翌日披露报表（NDR）阅读手册

## 1. 表格结构

FF305 表格通常包含：

- **第一章節 / Section 1**：按股份类别（普通股、其他类别）列示已发行股份与库存股份变动。
  - **A. 已發行股份或庫存股份變動事件**：逐项事件，含变动日期、股数变动、百分比、币种/价格、库存股数。
  - **B. 贖回/購回股份（擬註銷但尚未註銷）**：待注销存量，不是当日成交。
- **第二章節 / Section 2**：當日購回報告，含当日购回股数、价格总额、注销/库存目的。
- **第三章節 / Section 3**：庫存股份出售（如有）。
- 多类别股份会重复 A/B 块；页脚可能把标题切断。

## 2. 11 类内容（不要用交易所标签代替）

| 类别 | 判定 | 决策含义 |
|---|---|---|
| 新增購回 | Section 2 有成交，或 B 部有新增待注销 | 当日真金白银回购 |
| 購回並註銷 | 同日既新购回，又完成旧购回注销 | 回购 + 股本缩减 |
| 註銷購回股份 | 只注销旧购回，当日零成交 | 股本减少，但不代表当日护盘 |
| 配售/認購 | Section 1 正变动，描述含配售/认购 | 摊薄，关注折让与用途 |
| 供股 | 描述含供股 | 摊薄，关注包销与认购率 |
| 股份計劃發行 | 股份奖励/计划项下发行或转让库存股 | 摊薄或库存股消耗 |
| 期權行使 | 行使股份期权/购股权 | 温和摊薄 |
| 可換股轉換 | 可换股票据/债券转换 | 摊薄，注意转换价 |
| 內資股轉H股 | 内资股转 H 股 | **总股本不变，不是摊薄** |
| 以股代息 | 以股份代替现金股息 | 小额摊薄，节省现金 |
| 單位發行 | REIT 以基金单位支付费用 | 单位摊薄 |
| 股份合併/資本重組 | 股份合并/资本重组 | 机械性变动，需按换股比例重算 |
| 混合 | 同一份含两类以上事件 | 分别列示，不合并成单一结论 |

10-30 实际出现其中 11 类（新增購回、註銷購回股份、混合、購回並註銷、配售/認購、供股、股份計劃發行、內資股轉H股、以股代息、單位發行、股份合併/資本重組）；其余为低频或未出现类别。

## 3. 常见误判

1. **看标签不看 Section 2**：10-30 有 8 份“股份購回”当日零回购，只是注销旧购回。
2. **把 B 部当当日成交**：B 部是“待注销存量”，可能是过去多日累积；只有 Section 2 才是当日购回。
3. **把注销当利好**：注销只减少股本分母，不产生现金流；回购才是现金支出。
4. **把内资股转 H 股当摊薄**：总股本不变，只是股份类别转换。
5. **多类别串行**：第二类别的 A 块事件不能泄漏到第一类别的 B 部待注销。
6. **空字段**：“購回股份（擬持作庫存股份）數目”可能为空，应记 0，不是解析失败。
7. **多币种**：同一份可能 HKD/USD/GBP/RMB 并存，金额要分币种汇总，不能直接相加。
8. **页脚切断标题**：`A. 已發行股份…變動` 与 `事件` 可能跨页，解析要按整段文本而非单页。

## 4. 告警阈值（`config/analyzers/ndr.yaml`）

| 规则 | 计算 | P0 | P1 |
|---|---|---|---|
| 摊薄 | 新发行股数 / 期初股本 | ≥10% | 5–10% |
| 注销管道 | 待注销股数 / 期末股本 | — | ≥5% |
| 回购强度 | 回购股数 / 期末股本 | — | ≥1% |
| 注销强度 | 注销股数 / 期初股本 | — | ≥2% |

有行情时，回购金额同时给出占推算市值与当日成交额的比例；行情缺失时（`--no-market`）不按金额做跨公司比较，报告中必须写“未归一”。

## 6. 回答模板

1. 先给结论：当日有没有真回购、摊薄多大、注销管道多厚。
2. 再给数字与分母：股数、金额、占期初/期末股本。
3. 再给证据：时间、代码、公司、PDF 页码/原文行。
4. 最后给不确定性：市值是「期末股本 × 收市价」proxy、H 股股本口径、多币种、B 部存量非当日成交、低成交股成交额倍数失真。
