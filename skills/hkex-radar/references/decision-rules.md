# 决策与告警口径

## 1. 级别

| 级别 | 含义 | 典型触发 |
|---|---|---|
| P0 | 当天必须看，可能改变对公司/股东的判断 | 停牌/复牌、核数师辞任、重大交易、摊薄 ≥10%、清盘/违约/退市 |
| P1 | 值得跟踪，可能影响未来数日 | 回购强度 ≥1%、待注销 ≥5%、摊薄 5–10%、配售/供股、董事/CFO 变更 |
| P2 | 例行但仍需记录 | 常规回购、一般治理变更、例行股息公告 |

P0/P1 是“需关注”，不是“该买/该卖”。

## 2. NDR 公式

```
摊薄 %       = 新发行股数 / 期初股本 × 100
注销管道 %   = 待注销股数 / 期末股本 × 100
回购强度 %   = 当日回购股数 / 期末股本 × 100
注销强度 %   = 当日注销股数 / 期初股本 × 100
```

阈值在 `config/analyzers/ndr.yaml`。分母必须写清；没有期初/期末股本时不得猜。

**非摊薄事件**：內資股轉H股、股份合併/資本重組。前者总股本不变，后者是机械性变动，均不触发摊薄告警。

## 3. 后续族的指标

- 资本动作：摊薄 %、相对市价折让 %、募资额/市值、用途、锁定期、大股东参与。
- 交易：代价/市值、资产/利润/收入/代价四项规模比率、关连属性。
- 业绩：收入/利润/EPS 同比、毛利率、股息变化、指引。
- 治理：角色关键性 × 离任原因 × 继任安排；核数师更换单独加权。
- 停复牌：直接 P0。

## 4. 证据规则

1. 每个数字带 `page` 与 `quote`；`quote` 必须是 PDF 原文子串。
2. 抽取失败或引文校验失败：丢弃该事实或降置信度，并在报告中标注“未核验”。
3. 算术校验：期初 + 变动 = 期末；股数 × 价格 ≈ 金额；不一致时保留事件但标 warning。
4. 多币种分开列示，不做汇率折算，除非明确给出汇率来源。
5. 有行情时，绝对金额要同时给出占推算市值 / 当日成交额的比例；行情缺失时，禁止用绝对金额做跨公司影响力排序。
6. 市值是「股本 × 收市价」的 proxy；股本来源与 H 股口径必须在报告中交代。

## 5. 输出格式

```
结论（1–2 句）
关键数字（带分母与单位）
证据（时间 / 代码 / 公司 / 页码或原文）
不确定性（数据缺口、口径、未归一）
```

## 6. 当前数据缺口

- 行情：收盘价、推算市值、当日成交额已接入（P2b）；20 日 ADV 有工具但未批量接入。
- 财务：收入、利润、资产、股本（P4）。
- 行情缺失时，NDR 只按股本比例判断；交易族只做标题级与代价/市值近似。
